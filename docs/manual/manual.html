📘 Manual de Uso — Movi Exporter

Guia passo a passo para extrair os relatórios mensais de rastreamento dos seus veículos.

Versão 1.4.0

Introdução

O Movi Exporter é um aplicativo de computador que conecta na sua conta Wialon e gera relatórios mensais dos seus veículos em planilha (CSV ou Excel), com opção de enviar automaticamente para o Google Drive.

Este manual cobre desde a primeira configuração até a geração do relatório. Siga os passos na ordem na primeira vez que usar.

O que você vai precisar Um token de acesso da Wialon (explicamos como gerar no passo 2). Opcionalmente, as credenciais do Google Drive se quiser envio automático.

1Instalar o aplicativo

  1. Baixe o arquivo MoviExporter.exe (Windows) da página de versões.
  2. Dê dois cliques no arquivo para abrir. Não precisa instalar — ele roda direto.
  3. Na primeira vez, o Windows pode mostrar um aviso de segurança. Clique em "Mais informações" e depois "Executar assim mesmo".
Aviso de segurança é normal Como o app é distribuído internamente, o Windows não "reconhece" o desenvolvedor. Isso não significa que o arquivo é perigoso — é só um aviso padrão para programas sem certificado pago.

2Configurar o token da Wialon

O token é a "chave" que permite o app acessar seus veículos na Wialon. Você gera ele uma vez e cola no app.

2.1 — Abrir as Configurações

  1. No menu lateral esquerdo, clique em Configurações.
  2. Localize a seção "Wialon API — Conta 1".

2.2 — Gerar o token na Wialon

  1. Clique no botão Gerar. Isso abre a página de login da Wialon no seu navegador.
  2. Faça login com seu usuário e senha da Wialon e autorize o acesso.
  3. Depois do login, a Wialon gera o token e o devolve na barra de endereços do navegador, logo após access_token=.
  4. Copie o token da URL — a sequência longa após access_token= (até o próximo &, se houver).
Onde está o token? Depois de logar, olhe a barra de endereços do navegador: o token é o trecho que vem após access_token= — uma sequência longa de letras e números. É esse valor que você copia e cola no app.

2.3 — Salvar e testar no app

  1. Volte ao Movi Exporter e cole o token no campo Token.
  2. Clique em Salvar.
  3. Clique em Testar. Se tudo estiver certo, aparece Conectado como "seu_nome" com um ícone verde.
Dica O botão de olho ao lado do campo mostra/esconde o token, caso precise conferir o que foi colado.
Para a coluna Motorista funcionar Se você usa identificação de motorista por cartão RFID, o token precisa ter permissão de ver motoristas (marque o acesso aos motoristas ao autorizar) e cada cartão precisa estar com o campo "Código" preenchido na Wialon. Sem isso, a coluna Motorista do relatório sai como N/D.

3Entendendo a tela inicial

A tela inicial mostra o status das conexões em três cartões.

  • Wialon API — mostra se o app está conectado. Verde = tudo certo.
  • Veículos — quantidade de veículos encontrados na sua conta.
  • Google Drive — se o envio automático está configurado.

Os botões Testar Conexões e Ver Veículos permitem reverificar o status e listar todos os veículos a qualquer momento. Abaixo, o bloco Resumo de Exportações mostra a última exportação realizada (com botão para abrir a pasta), sugere o mês que ainda falta exportar e exibe estatísticas do ano.

4Google Drive (opcional)

Se quiser que os relatórios sejam enviados automaticamente para uma pasta do Google Drive, configure esta seção. Caso contrário, pode pular.

4.1 — O que você precisa

  • Arquivo de credenciais (client_secrets.json) — o arquivo de autenticação do Google. Solicite ao desenvolvedor e coloque-o na mesma pasta do MoviExporter.exe.
  • ID da pasta do Drive — identifica a pasta de destino dos relatórios (veja abaixo como obter).

4.2 — Descobrir o ID da pasta

  1. Abra o Google Drive no navegador e entre na pasta de destino.
  2. Olhe a URL: drive.google.com/drive/folders/ESTE_TRECHO.
  3. Copie o trecho depois de /folders/ — esse é o ID da pasta.

4.3 — Configurar no app

Em Configurações → Google Drive:

  • Credenciais — mostra "✅ Encontrado" quando o client_secrets.json está na pasta certa.
  • ID da pasta — cole o ID copiado e clique em Salvar.

Depois, marque "Upload para Google Drive" na tela de exportação para o envio automático.

Organização no Drive Os relatórios sobem organizados por mês. Se você usa duas contas, cada uma vai para sua subpasta (Conta 1/ e Conta 2/), sem misturar.

5Segunda conta Wialon (opcional)

Se você gerencia veículos em duas contas Wialon diferentes, pode configurar a segunda na seção "Wialon API — Conta 2", seguindo os mesmos passos do passo 2.

Quando a Conta 2 está configurada Aparece um seletor de conta no menu lateral (esquerda). Trocar a conta ali reflete em todas as telas — a tela inicial e a de exportação passam a usar a conta escolhida. Os relatórios de cada conta vão para subpastas separadas (Conta 1/ e Conta 2/).

6Fazer uma exportação

Este é o passo principal: gerar o relatório de um mês.

  1. No menu lateral, clique em Exportar.
  2. Escolha o Mês (por nome: Janeiro, Fevereiro…) e o Ano (ambos em listas suspensas).
  3. Escolha o Formato: csv (planilha simples), xlsx (Excel) ou both (os dois).
  4. Se você tem duas contas, confirme no menu lateral qual Conta está selecionada.
  5. Marque "Gerar arquivo consolidado" se quiser um único arquivo com todos os veículos juntos.
  6. Marque "Upload para Google Drive" se configurou o Drive e quer envio automático.
  7. Marque "Incluir endereço (mais lento)" se quiser a coluna Localização preenchida com o endereço de cada ponto. Vem desmarcado por padrão — a busca de endereços deixa a exportação mais demorada.
  8. Para exportar todos os veículos, deixe "Todos os veículos" selecionado. Para escolher veículos específicos, marque "Selecionar veículos" e clique em Carregar (veja a busca abaixo).
  9. Clique em Iniciar Exportação.
Buscando veículos específicos (frotas grandes) Ao marcar "Selecionar veículos", nenhum vem marcado por padrão. Use o campo de busca para filtrar por nome, placa ou ID e marque só os que quer. Os botões "Marcar todos" / "Desmarcar todos" agem sobre o resultado da busca atual. Em listas muito grandes, aparece "Mostrar mais" para carregar o próximo lote. Um contador mostra quantos estão selecionados.
Quanto tempo leva? Depende da quantidade de veículos e de dados do mês. Frotas grandes podem levar alguns minutos. Acompanhe pelo registro de progresso na tela.

7Encontrar os arquivos gerados

  1. Após a exportação, clique no botão Abrir pasta.
  2. A pasta do mês abre automaticamente no explorador de arquivos.

Os arquivos ficam organizados por ano e mês, por exemplo:

  • exports/2026-04/ — relatórios de Abril de 2026
  • Cada veículo tem seu arquivo (nomeado pela placa), mais o consolidado, se marcado.
Por que alguns arquivos têm um número no nome? O nome do arquivo vem da placa cadastrada na Wialon (campo registration_plate) — por exemplo RJG0H60_Histórico_Padrão_…. Quando duas unidades têm a mesma placa cadastrada (placa repetida por engano, ou dois rastreadores no mesmo veículo), o app anexa o ID da unidade na Wialon ao nome, ficando RJG0H60_402231059_Histórico_…. Isso garante que um arquivo nunca sobrescreva o outro e que dê para identificar exatamente a qual unidade cada relatório pertence. Se isso aparecer com frequência, vale conferir o cadastro de placas na Wialon.

9Variáveis de ambiente (avançado)

Para uso normal você não precisa mexer aqui: o token e o ID da pasta do Drive são gravados pelo próprio app quando você clica em Salvar nas Configurações. Esta seção é só para ajustes avançados.

As configurações ficam num arquivo chamado .env, na mesma pasta do MoviExporter.exe.

Criar o arquivo .env no Windows

  1. Abra o Bloco de Notas.
  2. Em Arquivo → Salvar como, escolha "Tipo: Todos os arquivos".
  3. Nomeie exatamente .env (com o ponto, sem .txt) e salve na mesma pasta do .exe.

Dúvidas comuns

A exportação diz "0 registros". O que houve?

Significa que não havia dados para o período escolhido. Pode ser que os veículos estivessem inativos no mês, ou que a conta Wialon não guarde histórico tão antigo. Tente um mês mais recente.

O que significa "N/D" em algumas colunas?

"N/D" = "Não Disponível". Indica que aquele sensor não enviou dado naquele momento (ex: um veículo parado pode não reportar tensão do motor). É normal e esperado.

A coluna Motorista está vazia (N/D). Como preencher?

O nome do motorista vem do cartão RFID. Para aparecer: o token da Wialon precisa ter permissão de ver motoristas e cada cartão precisa estar com o campo "Código" preenchido na aba Motoristas da Wialon. Sem isso, ou em linhas onde nenhum cartão foi passado, a coluna fica N/D — o restante do relatório continua normal.

Marquei a exportação mas a coluna Localização está vazia. Por quê?

A coluna Localização só é preenchida se você marcar "Incluir endereço (mais lento)" na tela de exportação (vem desmarcada por padrão porque deixa o processo mais demorado). Pontos sem endereço mapeado também podem sair como N/D.

Qual a diferença entre "Tensão do Veículo" e "Bateria Interna"?

Tensão do Veículo (~12V a 28V) é a bateria do carro/caminhão. Bateria Interna (~4V) é a bateria de reserva do próprio rastreador. São informações diferentes.

Preciso configurar o token toda vez?

Não. Depois de salvar uma vez, o app lembra o token. Só precisa reconfigurar se trocar de conta ou se o token expirar.

O Windows bloqueou o app. É vírus?

Não. É um aviso padrão para programas sem certificado de desenvolvedor pago. Clique em "Mais informações" → "Executar assim mesmo".

Como mudo entre tema claro e escuro?

Em Configurações → Geral → Tema, escolha Escuro, Claro ou Sistema (segue o tema do seu computador). A escolha é lembrada na próxima vez que abrir o app.

Onde abro este manual de dentro do app?

No rodapé do menu lateral há os botões Manual (abre este guia no navegador) e Sobre (versão do app, links e verificação de atualização).
